# 📝 TodoList — Organizador de Tarefas

Um organizador de tarefas desenvolvido com **React e JavaScript**, com o objetivo de praticar conceitos fundamentais do desenvolvimento Front-end e criar uma aplicação que ajude na organização e na produtividade do dia a dia.

O projeto faz parte da minha jornada de aprendizado em desenvolvimento de software, com foco na construção de interfaces, componentização e gerenciamento de estado no React.

## 🚀 Tecnologias utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Git e GitHub

## ✨ Funcionalidades

- [x] Interface para organização de tarefas.
- [x] Adição de novas tarefas.
- [x] Componentes reutilizáveis.
- [x] Gerenciamento de estado com `useState`.
- [ ] Marcação de tarefas como concluídas.
- [ ] Filtro de tarefas por status.
- [ ] Indicadores de progresso.
- [ ] Armazenamento de tarefas no navegador.
- [ ] Integração com uma API para exibir curiosidades ou frases motivacionais.

> As funcionalidades serão atualizadas conforme o desenvolvimento do projeto avançar.

## 💻 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm

### Instalação

**1. Clone o repositório:**

```bash
git clone URL_DO_SEU_REPOSITORIO
```

**2. Acesse a pasta do projeto:**

```bash
cd todolist
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento:**

```bash
npm run dev
```

**5. Acesse o endereço exibido no terminal**, normalmente `http://localhost:5173`.
